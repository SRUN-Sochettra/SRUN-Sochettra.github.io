Overview

A REST API for a blog backend built with Spring Boot, centered on JWT authentication, PostgreSQL persistence, MyBatis data access, and Pinata IPFS file uploads.

Capabilities

What it does

  • JWT authenticationToken-based authentication securing the blog API endpoints.
  • PostgreSQL persistenceRelational storage for the blog's data.
  • MyBatis data accessSQL-mapper–based persistence layer over PostgreSQL.
  • Pinata IPFS uploadsFile uploads stored on IPFS via Pinata.
